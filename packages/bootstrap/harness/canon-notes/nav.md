# nav

`ul.nav` by default. `as="nav"` is a `nav` with no `li`.

`tabs` / `pills` / `underline` add `nav-tabs`, `nav-pills`, or `nav-underline`. `vertical` replaces the variant with `nav-pills` and `nav-pills-vertical`. `fill` and `justified` add `nav-fill` and `nav-justified`.

`Item` is `li.nav-item`. `Link` is `a.nav-link`. `active` adds `.active` and `aria-current="page"`. `disabled` adds `.disabled`, `aria-disabled="true"`, omits `href`, and sets `tabindex="-1"`.

No `role="tab"`. No selection. No `data-bs-toggle`. This is not BTabs.
