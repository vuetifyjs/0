# card

Root is `section.card`. `as` changes the host. `subtle` adds `card-subtle`. `translucent` adds `card-translucent`.

`Header` is `div.card-header`. `Body` is `div.card-body`. `Title` is `h4.card-title` (`as` changes the heading). `Subtitle` is `p.card-subtitle`. `Text` is `p.card-text`.

No footer part. `.card-footer` stays a class the consumer writes.
