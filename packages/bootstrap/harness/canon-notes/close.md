# close

`button.btn-close` with `type="button"`. No children. The glyph is the class.

Accessible name is `locale.ti('Close.label')`, falling back to `Close`. `disabled` is the native attribute. No click handler. No `data-bs-dismiss`.

`BDialogClose` is a different button. It uses `Dialog.close` and closes the dialog. This one does not.
