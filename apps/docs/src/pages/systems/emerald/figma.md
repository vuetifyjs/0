# Figma

<DocsPageFeatures :frontmatter />

The Vue package is MIT. The Vuetify Store sells the Figma file separately. The file uses the same `--emerald-*` token names, the same `Em*` parts, and the same `emerald-light` and `emerald-dark` themes. You can build from these docs and the source without the file.

The kit includes Figma variables that match the CSS token names, every shipped `Em*` family with its variants and parts, the icon set (48 glyphs, 72 names), and layouts from the [dashboard](/demo/emerald/).

Buy it on the [Vuetify Store](https://store.vuetifyjs.com/products/official-emerald-ui-kit-for-figma). Licenses are Personal, Commercial, and Unlimited. They cover the Figma file. The Vue package stays MIT.

The [tokens](/systems/emerald/tokens) page lists the CSS token names. [EmIcon](/systems/emerald/icon) lists the icon roles.
