# v0play export

Scaffold exported from [Vuetify0 Play](https://v0play.vuetifyjs.com). It is a Vite + Vue 3 + TypeScript app with UnoCSS and your playground files under `src/`.

## Quick start

```bash
# install (pick one)
pnpm install
# npm install
# yarn

# run the dev server
pnpm dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Icons (optional)

If you used Iconify classes in the playground (`i-lucide-home`, `i-mdi-home`, …), add the same setup locally:

1. Install `@iconify-json/*` collections you need, or rely on Iconify’s CDN via UnoCSS preset-icons.
2. Enable `presetIcons` in `src/uno.config.ts` (see the [UnoCSS icons docs](https://unocss.dev/presets/icons)).

Playground defaults load collections from the CDN on first use; a local export may need the preset wired explicitly if you customized `uno.config.ts`.
